# Hatchling

Horror parasite lifecycle mod for **Minecraft 1.21.1** (Fabric).

Eggs hatch into larvae that hunt cows, incubate on their backs, then burst
the host into a hostile alien — which lays and throws more eggs until
population and generation caps stop the spread.

```
EGG (block / thrown) → LARVA → latch on COW → incubate → BURST → ALIEN
         ↑                                                         |
         +-------------------- lay / throw eggs -------------------+
```
